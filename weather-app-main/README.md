# Weather App

A simple, responsive Weather App built with HTML and CSS. It displays current weather information using browser APIs or a weather API (if added).

## Overview

- **Project:** Weather App
- **Author:** TheSatwiksss

## How to run

1. Open `index.html` in your browser.
2. (Optional) Add a weather API key and JavaScript code if you want live data.

## Features

- Responsive layout
- Modern gradient background and UI
